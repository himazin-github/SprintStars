# Speed Stars (Ad-Free & Lightweight Edition)

陸上短距離走ゲーム **「Speed Stars」** を GitHub Pages にアップロードするだけで遊べるように最適化したパッケージです。

広告の完全排除、不審なトラッキングの除去、不要なSDKの削除による大幅な軽量化を行っています。

---

## 🚀 GitHub Pages で公開して遊ぶ手順

1. **GitHub に新しいリポジトリを作成**（Public または GitHub Proなら Private でも可）
2. 本フォルダ内のファイル・フォルダ（`.nojekyll`, `index.html`, `Build/`, `README.md`）をそのまま GitHub リポジトリに push（またはブラウザからアップロード）
3. GitHub のリポジトリページで **Settings** > **Pages** を開く
4. **Branch** を `main`（または `master`）、フォルダを `/ (root)` に設定して **Save** をクリック
5. 数分待つと表示される公開URL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）にアクセスすれば、ブラウザ上で即座にゲームが遊べます！

## 🎮 操作方法 & スマホでの遊び方

- **走る（スプリント）**:
  - **PC**: `◀` `▶` キー または `A` `D` キー を交互に連打！
  - **スマホ**: 画面の左半分と右半分を交互にタップ！
- **スマホ（Android / iOS）での操作 & 全画面**:
  - **走る**: 画面の左半分（◀ L）と右半分（R ▶）を交互に指で連打！タップ時にピカッと光るフィードバックが表示されます。
  - **Android (Chrome)**:
    - 読み込み完了後に表示される「TAP TO PLAY」をタップすると、ナビゲーションバーを隠した**完全没入フルスクリーン（Immersive Mode）**＆横画面固定（Landscape Lock）が自動実行されます。
    - **端末の自動回転がOFF（縦向き固定）**になっている場合でも、画面中央の「回転ロックのまま横画面で遊ぶ」ボタンを押せば、仮想横画面モードで即座にフルスクリーンプレイできます！
    - 連打時のダブルタップ拡大やピンチズームは完全に防止されているため、本気でスプリント連打が可能です。
  - **iPhone (Safari)**: 横向きにするだけで画面いっぱいにフィット。Safariの「共有」＞「ホーム画面に追加」でアドレスバーのない完全全画面アプリとして起動可能。
  - **全画面切り替えボタン**: 画面右下のボタンからいつでも全画面のオン/オフが可能です。

## ✨ 施した最適化と特徴

1. **GitHub Pages 即時対応**:
   - `.nojekyll` を同梱し、Unity WebGL のバイナリ・アセットが確実に配信されるように設定。
   - ルート配置でもサブディレクトリ配置（`/<repo-name>/`）でも問題なく動く相対パス設計。
   - GitHub の単一ファイルサイズ上限（100MB）内に収まっているため、通常の `git push` だけでアップロード可能（Git LFS 不要）。

2. **広告の完全排除 & リワード即時アンロック**:
   - Poki SDK の広告モジュール（バナー広告、インタースティシャル広告、動画広告）を完全排除。
   - リワード広告（動画を見ると報酬がもらえるボタン等）は、**広告動画を見ることなく即座に報酬が手に入る仕様**に変更！
   - ドメインチェック（特定サイト以外で動かすと強制リダイレクトされる制限コード）を解除。

3. **大幅な軽量化 & 高速起動**:
   - 巨大な外部 SDK（Poki SDK Core、トラッキングスクリプト等）や不要なスライドショー画像を全削除。
   - 外部 CDN や外部フォント、不審なテレメトリ送信サーバーへの通信を完全カット。
   - 軽量なスタンドアロンローダーに一本化し、ページアクセス後すぐにゲームのダウンロードと起動が開始されます。
